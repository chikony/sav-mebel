# САВ Мебель - Интернет-магазин мебели

Современный интернет-магазин мебели, разработанный на Vue.js 3 с использованием TypeScript, Vite, Vue Router и Pinia.

## 🚀 Особенности

### Функционал сайта:
1. **Каталог товаров** - просмотр мебели по категориям с фильтрацией и сортировкой
2. **Карточка товара** - детальная информация, характеристики, фото
3. **Отзывы о товарах** - возможность оставлять оценки и комментарии
4. **Корзина** - добавление товаров, изменение количества
5. **Оформление заказа** - форма с доставкой и оплатой
6. **Профиль пользователя**:
   - Личные данные
   - История заказов
   - Отслеживание статуса заказов
7. **Вход и регистрация** - аутентификация пользователей
8. **Раздел "О нас"** - информация о компании
9. **Админ-панель**:
   - Управление товарами (CRUD)
   - Управление заказами
   - Управление пользователями
   - Статистика

## 🛠 Технологии

- **Vue.js 3** - фреймворк с Composition API
- **TypeScript** - типизация
- **Vite** - сборка и dev-сервер
- **Vue Router 4** - маршрутизация
- **Pinia** - управление состоянием
- **CSS Variables** - стилизация

## 📦 Установка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр сборки
npm run preview
```

## 🔗 Маршруты

### Публичные:
- `/` - Главная страница
- `/catalog` - Каталог товаров
- `/catalog/:category` - Категория товаров
- `/product/:id` - Карточка товара
- `/about` - О нас
- `/cart` - Корзина
- `/login` - Вход
- `/register` - Регистрация

### Защищенные:
- `/profile` - Профиль
- `/profile/orders` - Заказы
- `/checkout` - Оформление заказа

### Админ:
- `/admin` - Главная админ-панели
- `/admin/products` - Товары
- `/admin/orders` - Заказы
- `/admin/users` - Пользователи
